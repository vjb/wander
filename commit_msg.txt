fix: add missing 'import re' — caused all route polylines to be empty

The re module was used in _fetch_leg (re.sub to strip HTML from step
instructions) but was never imported. The NameError was silently swallowed
by the broad except clause, causing every leg to return polyline="" and
steps=[], so WanderMap fell back to drawing straight lines between stops.

- Cap combined insider tip at 160 chars to prevent overflow
- Improve _fetch_leg exception logging (was silent, now logs warning)
- Escalate polyline decode errors from warning to error level
